PTAF Sentinel_open source · MIT · beta v0.2.0

Unit tests for your detection rules.

PTAF Sentinel runs harmless imitations of attacker behavior on a machine, runs your Sigma rules against that machine's own process telemetry, and tells you which behaviors were caught, missed, or newly stopped being caught.

View on GitHub Download v0.2.0 (beta)

Find silent failures

A rule that exists is not a rule that fires. Our own example rule had a doubled backslash and passed syntax checks for weeks while it could never match.

Rule gap or blind sensor?

"Missed" and "no telemetry" are different statuses. ptaf selftest exits 0 (ok), 1 (gap or drift) or 3 (sensor problem), with JUnit output.

Bring your Sigma rules

ptaf rules check <dir> shows which of your rules PTAF can run. On public SigmaHQ process-creation rules, 1,304 of 1,383 (94%) are runnable. Runnable does not mean the rule is good.

Try it

git clone https://github.com/Mangesh-Bhattacharya/Purple-Team-Automation-Framework.git
cd Purple-Team-Automation-Framework
python3 -m venv .venv && . .venv/bin/activate
pip install .
ptaf up

It starts the agent and a live dashboard. In one measured run on macOS the server was up in about 1.9 s and first real results arrived in about 10.8 s. ptaf canaries lists exactly what will run (19 canaries, 21 rules today).

Use only on systems you own or are authorized to test. Its tests can trigger security alerts.

Honest limits

  • Process-creation telemetry only; no network, file, registry or authentication rules yet.
  • On Windows and macOS the sensor polls every 50 ms and can miss very short-lived processes.
  • Tested on CI runners and one developer Mac, not on hardened or EDR-protected fleets, physical machines, ARM or NetHunter Kali.
  • Release apps are unsigned, so expect OS warnings. English only; no central console yet.
  • The five dashboard agents are rule-based, not an AI model.
  • A pass means one harmless test was caught by one rule on that machine at that time. It is not a security guarantee, and PTAF does not replace your SIEM or EDR.
